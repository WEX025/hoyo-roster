# 隐私、存储和清理

工具处理本人游戏角色状态并将受支持结果保存到本机。客户端浏览器的登录态包含敏感认证信息，不属于正式游戏结果。

## 客户端浏览器会话

登录使用当前 AI 客户端的内置浏览器。用户在官方页面自行处理手机号、短信验证码、扫码、协议与图片验证；AI 不索取或代填、不代发短信、不代勾协议、不代提交登录。浏览器正常与官方页面及其引用服务通信。

用户确认完成后，登录模块交接同一活会话和页面引用；浏览器负责保持会话。模块之间不读取、导出、复制 Cookie/token，不导出 Profile、不收集登录表单值，也不把认证状态写入仓库。页面采集只读官方角色面板身份和游戏业务显示值，包括原神计算器的当前等级输入；不读取手机号、验证码等登录输入值。交接引用只用于当前运行上下文，不是可复制到其他客户端或 Python 的凭据。

当前 Codex 内置浏览器中已观察到原神刷新/重开及绝区零绑定角色页面复用；不承诺客户端退出/重启后仍保持，也不代表所有客户端或操作系统均支持。正常采集不保存账号截图、HAR、trace 或认证响应；页面结果仅保存已说明的业务字段和必要身份，反馈时应脱敏。

客户端宿主与 Python 之间为私有进程管道，不在可见终端展示。客户端仅发送确切业务来源 JSON 及覆盖证据，Python 不获取浏览器登录材料。--runtime-root 下 client-runtime-v1 仅含锁/请求节流元数据。

本人旧认证和结果目录保留原地，不搜索、不读取、不复制、不迁移、不删除。退出登录须在确切客户端官方页面操作。工作进程退出会保留客户端浏览器；完整数据能力缺失时明确失败，不另起浏览器。


## 结果保存

每个游戏自行发现和精确核验官方游戏/UID/区服，采集、验证并保存。登录模块里的用户确认不是身份或数据成功证据。账号冲突停止，不能把另一账号的数据写进已有身份范围。

结果默认在已核验的本项目源码仓库 data/game-results-v3/ 下；无可核验源码的安装回退系统用户数据目录的 results/。--storage-root 只覆盖结果。游戏/UID 派生哈希用于隔离，哈希不是加密匿名化；不要公开分享整个目录。

工作区身份边界、候选、代际、请求节流和恢复日志依各自范围保存。提交前失败保留旧 current；持久化未知时保留所有可能被引用的代际和日志；已提交的清理失败独立报告待办。检查和恢复见[本机使用](local-use.md#检查与恢复)，文件系统边界见[平台支持](platform-support.md)。

正常同步不提交或上传个人结果，不发送给项目作者或 GitHub。源码 data/ 只跟踪 .gitkeep；忽略规则不保护已经跟踪、强制添加或整个目录打包的内容。提交前运行 python tools/check_private_data.py，仅检查 Git 索引路径，不读取私人内容。

## 输出、反馈和卸载

只报告模块状态、非敏感数量、固定错误代码及必要的本机结果路径。公开反馈中路径也应脱敏，不附真实 UID、昵称、手机号、验证码、账号截图、Cookie/token、浏览器目录、设备头、原始响应或个人 JSON。命令行输入的 UID 可能留在 shell 历史和进程参数中。

卸载 Python 包不会清理客户端登录态或旧认证目录，也不删除正式结果。删除源码克隆前核对并私下备份其中的 data/。任何清理都只针对明确核验的自有范围；不按 UUID 盲删，不删除共享父目录，不以清理登录态为由清空游戏结果。模块边界和完整工作流见[四模块工作流](workflow.md)。
