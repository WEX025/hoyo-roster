# 隐私、存储和清理

工具保存本人角色状态到本机。浏览器 Profile 包含敏感 Cookie/登录状态，绝不属于正式结果；另有 scope-local HMAC key、身份指纹、持久工作区身份边界（游戏/UID 摘要/区服）、节流时间、候选、代际和恢复日志。隔离目录使用游戏/UID 派生哈希，哈希不是加密匿名化，不能公开分享整个目录。

正常同步不 fetch/commit/push，不上传给项目作者、GitHub 或任何其他数据仓库；浏览器仍与官方服务及官方页面引用的服务通信。本项目不规避官方风险控制。结果默认 `<已核验的本项目仓库>/data/users/<scope>/<game>/<hash>/`；克隆后普通 `pip install .` 也适用。无法核验源码的独立安装回退到 `~/.local/share/hoyo-roster/results/users/<scope>/<game>/<hash>/`，不写包安装目录，不依赖 cwd。`--storage-root` 仅覆盖结果。

认证仍默认 `~/.local/share/hoyo-roster/users/<scope>/<game>/<hash>/`，`--auth-root` 只选择仓库外的私有认证根。Profile、HMAC key、已验证指纹、认证锁和节流属于认证范围；候选、工作区身份、代际、当前指针及恢复日志属于结果范围。不自动迁移或删除旧范围，不能将旧 storage-root 连同 Profile 整体搬到源码 `data/`。旧根复用和人工迁移边界见 [本机使用](local-use.md#升级)。

本轮新建应用目录每层 0700，普通数据/元数据 0600；clone 的顶层 data/ 可保持属于本人且不可被其他人写入的 0755，身份子目录为 0700。不会 chmod 用户已有共享父目录或安全配置。Chromium 自己创建的内部文件可能有不同权限，但 Profile 根为 0700。持有本机用户权限的人仍可读取数据，文件权限不替代系统账户安全。

输出为固定进度标签、错误代码、少量数量/本机恢复标识及准确结果路径（RESULT_SCOPE、CURRENT_POINTER、CURRENT_RESULT）；公开反馈时路径也应脱敏。程序不输出手机号、验证码、Cookie、token、设备头值、原始响应、昵称或 UID。你在 shell 中输入 UID 可能被 shell 历史和进程参数记录；如需反馈，手动脱敏命令。程序禁用下载接受和视频录制，不建立 HAR、trace 或截图；不要用浏览器调试导出登录材料。

源码 `data/` 只跟踪 `.gitkeep`，`.gitignore` 忽略全部个人结果。普通 `git add .` 会忽略这些文件，但已跟踪文件、`git add -f` 或整个目录打包仍可泄露；忽略不是隐私权限。禁止提交个人结果；提交前运行 `python tools/check_private_data.py`，检查只读取 Git 索引路径，不读取个人内容，发现 `data/` 内除顶层占位文件外任何跟踪路径都会失败。

源码版本升级不会清理个人数据。退出登录仅清理选定身份的 Profile/身份指纹；工作区身份与区服绑定继续保留；已采集数据、节流和恢复记录保留。候选失败通常安全清理，清理失败需 inspect 和显式 cleanup-candidate。提交持久化未知时同时保留新旧代际，不可删除可能被 current 引用的目录。

清理全部个人痕迹需本人关闭工具及确切浏览器进程，私下核对所选范围，按需求备份正式 JSON，然后删除该范围的 Profile、key、指纹、节流、candidates、代际和指针/恢复日志。其他身份和共享目录应保留。卸载包或删除源码虚拟环境不会删除个人范围；删除整个源码克隆会同时删除其中 data/ 结果，须先核对并私下备份；仓库外认证不随克隆删除。系统缓存中的 Chromium 安装由 Playwright/用户管理。

问题反馈仅附版本、平台、固定错误代码和脱敏后的重现步骤。不要附完整本机路径、UID、昵称、手机号、验证码、登录截图、浏览器目录、原始响应或个人 JSON。分享个人正式结果到自己的仓库是另一个需要核实 owner、visibility 和范围的授权动作，当前工具不提供自动发布命令。
