# 隐私、存储和清理

工具保存本人角色状态到本机。浏览器 Profile 包含敏感 Cookie/登录状态，绝不属于正式结果；另有 scope-local HMAC key、身份指纹、节流时间、候选、代际和恢复日志。隔离目录使用游戏/UID 派生哈希，哈希不是加密匿名化，不能公开分享整个目录。

正常同步不 fetch/commit/push，不上传给项目作者、GitHub 或任何其他数据仓库；浏览器仍与官方服务及官方页面引用的服务通信。本项目不规避官方风险控制。数据路径默认 `~/.local/share/hoyo-roster/users/<scope>/<game>/<hash>/`，只有当事人的本机命令可以自行定位。

本轮新建应用目录每层 0700，普通数据/元数据 0600；不会 chmod 用户已有共享父目录或安全配置。Chromium 自己创建的内部文件可能有不同权限，但 Profile 根为 0700。持有本机用户权限的人仍可读取数据，文件权限不替代系统账户安全。

输出为固定进度标签、错误代码和少量数量/本机恢复标识。程序不输出手机号、验证码、Cookie、token、设备头值、原始响应、昵称或 UID。你在 shell 中输入 UID 可能被 shell 历史和进程参数记录；如需反馈，手动脱敏命令。程序禁用下载接受和视频录制，不建立 HAR、trace 或截图；不要用浏览器调试导出登录材料。

源码版本升级不会清理个人数据。退出登录仅清理选定身份的 Profile/身份指纹；已采集数据、节流和恢复记录保留。候选失败通常安全清理，清理失败需 inspect 和显式 cleanup-candidate。提交持久化未知时同时保留新旧代际，不可删除可能被 current 引用的目录。

清理全部个人痕迹需本人关闭工具及确切浏览器进程，私下核对所选范围，按需求备份正式 JSON，然后删除该范围的 Profile、key、指纹、节流、candidates、代际和指针/恢复日志。其他身份和共享目录应保留。删除源码虚拟环境或卸载包不会删除个人范围；系统缓存中的 Chromium 安装由 Playwright/用户管理。

问题反馈仅附版本、平台、固定错误代码和脱敏后的重现步骤。不要附完整本机路径、UID、昵称、手机号、验证码、登录截图、浏览器目录、原始响应或个人 JSON。分享个人正式结果到自己的仓库是另一个需要核实 owner、visibility 和范围的授权动作，当前工具不提供自动发布命令。
