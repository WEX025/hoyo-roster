# 当前验证状态

当前代码按[四模块工作流](workflow.md)组织：账号共享认证，原神与绝区零各自采集并保存，崩铁公开采集仍暂停。当前使用以[本机指南](local-use.md)为准。

共享会话重构后的验证包含合成账号/页面/网络的业务链、认证过期恢复、游戏失败隔离、独立游戏契约、结果保存与关闭失败，以及本机离线浏览器和存储检查。合成测试与离线检查均不证明真实官方页面、真实登录或跨游戏账号会话已验收。

当前共享账号流程的真实登录、跨游戏复用、认证过期恢复及真实数据保存：**NOT_RUN**。当前版本的 Windows/Linux 实机及断电持久化：**NOT_RUN**。历史版本的真实通过结果不能覆盖这些范围。每次交付需另给固定源码 SHA、实际命令和原始结果。

旧的发布、架构、浏览器、登录和验证码阶段记录已移入[历史验证档案](history/README.md)；其中的旧入口、旧 Profile 放置、旧人工输入规则和测试数量均只解释当时版本，不作当前运行指引。
