# 数据与源码分享边界

代码、Schema、通用公开 ID 映射、合成配置示例可以组成干净的源码发行。
本仓库的 `data/` 是空 `not_synced` 基线，不包含任何人的 UID、昵称、角色池、装备或面板。

个人配置和浏览器登录状态必须放在仓库外。采集结果归各使用者独立维护，正常本地入口
不会把结果提交到 GitHub。公开展示柜数据不能代替已登录来源证明的完整角色池，UID 不能
绕过登录、隐私、绑定或风控要求。

若你明确选择把自己的角色池保存到自己的仓库，先核实目标账号、仓库可见性和需要提交的
游戏范围。只提交该游戏的正式 profile/roster/builds（ZZZ 另有 bangboos），不得提交
users.toml、Cookie/token、浏览器 Profile、数据库、原始响应或其他账号数据。这是独立授权
的上传操作，不是默认的 sync 行为，也不意味着不能由本人选择保存自己的数据。

`.gitignore` 只能防止新增未跟踪文件，不能清除已跟踪内容或历史。分享源码时使用全新、
经检查的空基线发行，不复制旧 `.git`、个人资料或登录状态。`tools/prepare_hoyo_share.py`
可以在新目录生成源码与空基线；它不是完整的凭据审计工具，分享前仍须检查打包内容。

本发行没有选择许可证、安装工作流或部署服务。公开可见不等于提供了开源许可证的使用授权；
许可证由仓库所有者另行决定。
